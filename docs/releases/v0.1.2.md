Claudgar now supports the released WoW Forever client.

- Detects and validates the `_forever_` installation.
- Moves saved beta folder selections to a verified release installation under the same World of Warcraft folder.
- Keeps beta character exports separate from release characters.
- Updates setup guidance and adds release compatibility and migration regression coverage.

**Upgrading from the beta:** Enable Claudgar in the release client and save each character using `/reload` or logout.

Tested in WoW Forever by the maintainer.

Download `Claudgar.exe` below for Windows 10/11 (64-bit). The addon and chat connection helper are included. Existing installations can use Claudgar's built-in updater.
