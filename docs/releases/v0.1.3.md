Claudgar now saves your WoW Forever character when the game hides the realm name. This fixes the “Character identity is restricted or loading” message that could repeat every time you clicked the minimap button.

The addon uses the player GUID to match an existing character record. Quests, talents, inventory, and equipment continue to update under that character.

After updating the Windows companion, type `/reload` once in Forever to load the new addon. Then click the Claudgar minimap button out of combat to save.
